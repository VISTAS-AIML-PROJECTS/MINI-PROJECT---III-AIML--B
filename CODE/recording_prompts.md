# EchoGenesis — Voice Fine-Tuning Recording Prompts

Read each sentence aloud naturally, as if speaking to a friend — not a
flat, robotic reading. Record each one as a SEPARATE short audio clip
(a few seconds each). Save them as prompt_001.wav, prompt_002.wav, etc.,
matching the numbers below — that pairing (audio file <-> exact text)
is what the fine-tuning process needs.

Aim for at least 30-40 clips total (more is better). Quiet room, mic
6-12 inches from your mouth, natural pace.

## Statements
001. The weather has been really nice this week.
002. I usually have coffee first thing in the morning.

004. We watched a movie together last night.
